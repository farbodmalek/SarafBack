# دیتابیس GirlyShop

1. در SSMS به `.\SQLEXPRESS` وصل شو (اگر LocalDB استفاده می‌کنی، `Server=` را در هر دو `appsettings.json` عوض کن).
2. به ترتیب اجرا کن:
   - `01_Schema.sql` — ساخت دیتابیس `GirlyShop` و همه‌ی جدول‌ها
   - `02_SeedCatalog.sql` — ۴ دسته، ۳ برند، ۸ محصول با واریانت و عکس نمونه
   - `03_DevUsersAndOrders.sql` — (اختیاری، فقط روی سیستم خودت) ادمین، مشتری نمونه، آدرس و ۴ سفارش
3. هر سه اسکریپت idempotent هستند؛ چندبار اجرا کنی تکراری نمی‌سازند.

| کاربر | موبایل | رمز |
|---|---|---|
| ادمین | 09120000000 | Admin@12345 |
| مشتری | 09121111111 | Test@12345 |

دیتابیس‌های قدیمی (`GirlyShopDb`، `online_shop_db`) دست نخورده‌اند؛ بعد از اینکه مطمئن شدی همه‌چیز کار می‌کند می‌توانی پاکشان کنی.
